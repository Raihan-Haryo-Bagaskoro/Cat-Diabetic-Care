Hubungkan Database Cloud (Firebase)

Agar akun dokter, akun pasien, dan laporan harian bisa dibuka di HP maupun laptop lain secara real-time, tempelkan URL Firebase Realtime Database Anda di bawah ini:

Cara Mendapatkan URL Gratis (2 Menit):
  1. Buka console.firebase.google.com → Buat Proyek Baru.
  2. Pilih menu Build → Realtime Database → Create Database.
  3. Pilih Start in test mode → salin tautan https://...firebasedatabase.app.
